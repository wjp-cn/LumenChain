## 已知限制

运行权限不足时可能需要配置降级进程名；名称降级会失去安装目录区分。启动器派生其他不同路径子进程时，需明确设置实际就绪进程名或使用 TCP/窗口标题条件。ShellExecute 提权不提供 PID，独立就绪条件仍可工作。

LNK 仅支持可解析为文件的目标。脚本参数遵循 cmd 语法，不能当作无执行能力的纯文本参数。远端 TCP 主机名的 Windows DNS 解析可能增加超时与取消的响应时间，建议本机检测填写 IP。

导入预览显示方案名称和条目数量，完整路径与参数需导入后在编辑器审阅。日志按批次标识提供文本过滤。Qt 标准图标提取失败会显示通用图标。

发行前还需人工验收上述项目、审阅第三方分发许可，并按需要加入代码签名和安装器。本次未签名。
